# Dataset

This project uses the **114000 Spotify Songs** dataset obtained from Kaggle.

The dataset contains approximately **114,000 Spotify tracks** spanning **125 genres**, with metadata and audio features used for exploratory data analysis and recommendation modeling.

## Dataset Features

The dataset includes:

- Track Name
- Artist
- Genre
- Popularity
- Danceability
- Energy
- Key
- Loudness
- Mode
- Speechiness
- Acousticness
- Instrumentalness
- Liveness
- Valence
- Tempo
- Duration

## Dataset Source

Kaggle — 114000 Spotify Songs  
https://www.kaggle.com/datasets/priyamchoksi/spotify-dataset-114k-songs

The complete dataset is not included in this repository because of its size.

To reproduce the project, download the dataset from Kaggle and place the required CSV file in the `data/` folder.

## Usage

The dataset was used for:

- Exploratory Data Analysis
- Content-Based Filtering
- KNN-based song similarity
- Collaborative Filtering
- SVD-based preference prediction
- Hybrid Recommendation
- Explainable AI
